## 5. Baseline defects relevant to v2

1. Download actions exist in the detail toolbar and lightbox, plus explanatory
   copy on home/about.
2. "Demo"/"Data demo"/"demonstrasi"/"contoh" labels appear across public and
   admin UI and in seed descriptions.
3. Admin create requires category and cover photo; gallery photos require a
   separate single-photo screen with title/alt/credit.
4. Admin navigation exposes Kategori, Data Foto and Pengguna, including a
   user-management screen with seeded user records.
5. Login is cosmetic; any email/password opens admin. Session is localStorage.
6. No backend persistence or server-side authorization.
